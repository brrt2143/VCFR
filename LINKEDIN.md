# Publicación de lanzamiento — borrador

Preparé VCFR (Voice Command For Readest), un compañero de lectura local para dar órdenes de voz, consultar un modelo en LM Studio y guardar párrafos en notas Markdown de Obsidian sin interrumpir la narración.

La demostración incluye una bóveda de Obsidian con *Don Quijote* de Project Gutenberg. También preparé un conector de acción para Calibre que abre el EPUB seleccionado en VCFR. En Readest, la integración actual usa controles y metadatos MPRIS cuando están disponibles; VCFR no se presenta como una extensión interna oficial de Readest.

El código de VCFR se publica bajo MIT. El EPUB de demostración conserva aparte sus avisos y condiciones de Project Gutenberg.
