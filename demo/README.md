# Video de demostración

`VCFR-Demo.mp4` presenta las funciones principales de VCFR con escenas gráficas hechas para el proyecto y narración sintética en español. No utiliza imágenes de stock ni audio grabado de una persona.

El texto está en [`narration-es.txt`](narration-es.txt); las imágenes fuente se generan con [`build_demo_scenes.py`](build_demo_scenes.py). [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) procesó las escenas en modo local; [FFmpeg](https://github.com/FFmpeg/FFmpeg) las unió en el orden de lectura y codificó el MP4. El audio se sintetizó en el equipo con [eSpeak NG](https://github.com/espeak-ng/espeak-ng), y las ilustraciones se dibujaron con [Pillow](https://github.com/python-pillow/Pillow). No se usaron claves de API ni servicios remotos para producirlo.

Las herramientas mencionadas conservan sus licencias y marcas originales; la licencia MIT de VCFR se aplica al código propio del proyecto.
